## What an integrator can actually reach

- [EA Account OpenID Connect discovery](https://accounts.ea.com/.well-known/openid-configuration): live
  OIDC Discovery 1.0 document (HTTP 200, Last-Modified 2026-09-02). Authorization endpoint
  https://accounts.ea.com/connect/auth, token endpoint https://accounts.ea.com/connect/token, userinfo
  https://accounts.ea.com/connect/userinfo, RS256 ID tokens, scopes openid/email/phone/profile.
- [EA OAuth authorization server metadata](https://accounts.ea.com/.well-known/oauth-authorization-server):
  RFC 8414 document (HTTP 200) advertising PKCE with S256.
- [EA Account JWKS](https://accounts.ea.com/connect/.well-known/openid-configuration/certs): live RSA
  signing keys.
- [EA SPORTS FC Community API](https://help.ea.com/en/articles/ea-sports-fc/community-api/): EA's only
  API programme. Players grant an approved community site permission to read Ultimate Team data —
  players, formations, tactics — through EA's OAuth flow. Approved partners: FUT.GG, FUTBIN, FUTWIZ.
  EA is not accepting further partner requests.
